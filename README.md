# Project Endless
 Simple Co-op game about developing the base

Небольшие тайлы открываются игроком
Прямое управление игроком
События привязаны к открытию новых тайлов - циклу
Несколько сезонов, сменяющие друг друга в определенном порядке во время смены цикла

Здания, которые добавляют игроку возможностей в пределах действия (дроны, усиление урона...), вместо турелей и юнитов
Башни с дронами, уничтожающими слабые отряды, ближе к концу игры
Здания для производства ресурсов, исследований и снаряжения. Производство может занимать больше одного цикла или делается сразу
Здания для быстрого перемещения: дороги, мосты, глайдеры

Ремонт зданий стоит часть ресурсов, затраченных на постройку. Прогресс производства теряется при уничтожении

Столкновение с противником открывает небольшую (в зависимости от врагов) арену, на которой происходит сражение
Два оружия игрока, движение. Дополнительно две ячейки под активный предмет
Пули и другие снаряды сталкиваются со снарядами врагов (кроме определенных), ослабляя и даже уничтожая их. Вражеские снаряды делают то же самое
Поражение игрока в сражении отправляет его на главную клетку, победа - убирает отряд с карты и дает ресурс

Случайные события при открытии новой клетки. Может быть связано с сезоном. Тип события показан на полоске времени
Варианты событий:
-До завершения цикла игрока преследуют отряды охотников. Уничтожение отряда вызывает еще один и т.д.
-Волна врагов. Волны врагов становятся сильнее по мере раскрытия карты
-Волна с минибоссом

Тайлы ограничены размером. Могут быть связаны с соседним тайлом, если касаются краями земли
Каждый тайл имеет собственный биом и может иметь простые ресурсы, специальный объект (сундук, головоломка, подземелье и т.д.)
Во время смены цикла на незастроенных клетках появляются до Х объектов, относящихся к тайлу

Ограничение на размер карт (количество тайлов) на каждом уровне? Клетка с крепостью врагов для прохождения уровня?
Артефакты, новые здания, ресурсы, враги, события на новых клетках? Погода?

Виды ресурсов? Базовые ресурсы не только возрождаются с открытием дверей, но и с небольшой скоростью появляются на соответствующей клетке

Условие выигрыша? Найти логово босса, пройти подземелье, убить босса
Условие проигрыша? Потеря главной клетки, потеря всех жизней (не здоровья)

Мультиплеер?
Кооперация - возможность оперировать зданием с производством для его ускорения. Игрок будет телепортирован к зданию при начале цикла
